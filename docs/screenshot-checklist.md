# Screenshot checklist

Capture screenshots from the locally running application after creating a disposable demonstration account. Do not include real personal data, passwords, session cookies, or secrets.

- [ ] Sign-in page at desktop width, showing the SecureAuth identity and form.
- [ ] Registration page with the password strength meter visible.
- [ ] Authenticated dashboard with account details and security status.
- [ ] Password checker showing a result for a made-up password; do not capture a password value.
- [ ] Account settings showing the change-password form, without filled credentials.
- [ ] Security Testing Center displaying the actual results of a run.
- [ ] Optional narrow/mobile-width view showing responsive navigation and cards.

Screenshots are not generated or represented as evidence until captured from a running instance.
